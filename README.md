# AI x Finance — Wall Street Hackathon

Basic scaffolding for the hackathon project.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python -m src.app.main
```

## Test

```bash
pytest
```

## Project layout

```
src/app/       application code
tests/         unit tests
requirements.txt
```
